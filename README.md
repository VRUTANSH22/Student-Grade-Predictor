# Student Performance Predictor 🎓

> A production-grade Flask web application that predicts student academic performance
> using a Random Forest + XGBoost ensemble model.

## Features

| Feature | Description |
|---|---|
| 🔮 **ML Ensemble** | Random Forest (60%) + XGBoost (40%) weighted average |
| 📊 **REST API** | 4 JSON endpoints with full Swagger docs at `/apidocs` |
| 🗄️ **Database** | SQLite (dev) / MySQL 8.0+ (production) via SQLAlchemy |
| 📝 **Logging** | Daily-rotating JSONL structured logs in `/logs/` |
| 🎨 **Frontend** | Dark-mode glassmorphism UI with animated result cards |
| 📋 **History** | Per-student prediction history with CSV export |
| 📈 **Dashboard** | Auto-refreshing KPI cards + grade distribution chart |
| ✅ **Tests** | Pytest suite: validators, API integration, model unit tests |

## Quick Start

### 1. Clone & create virtual environment

```bash
git clone <your-repo-url>
cd student_performance_predictor
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment

```bash
cp .env.example .env
# Edit .env — for development, the defaults work out of the box (SQLite)
```

### 4. Train the ML models

```bash
python train_models.py
```

This generates `models/random_forest_model.pkl`, `models/xgboost_model.pkl`,
and `models/scaler.pkl`. Expect R² > 0.90 on synthetic data.

### 5. Run the development server

```bash
python app.py
```

Open **http://localhost:5000** in your browser.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/predict` | Run a grade prediction |
| GET | `/api/history?student_id=STU001` | Prediction history |
| GET | `/api/stats` | System analytics |
| GET | `/api/health` | Health/liveness check |
| GET | `/api/recent` | Last 10 predictions (dashboard) |
| GET | `/apidocs` | Swagger UI |

### Example: POST `/api/predict`

```bash
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "student_id": "STU001",
    "student_name": "John Doe",
    "attendance_percentage": 85.5,
    "study_hours_per_week": 15,
    "assignment_score": 78,
    "quiz_marks": 82,
    "previous_gpa": 3.5
  }'
```

## Production Deployment (Gunicorn)

```bash
# Set USE_SQLITE=false and configure MySQL credentials in .env
gunicorn --workers 4 --bind 0.0.0.0:5000 --timeout 120 app:app
```

See [`docs/DEPLOYMENT_GUIDE.md`](docs/DEPLOYMENT_GUIDE.md) for full systemd service setup.

## MySQL Setup (Production)

```bash
mysql -u root -p < database/schema.sql
```

Update `.env`:
```
USE_SQLITE=false
DB_HOST=localhost
DB_NAME=student_predictor
DB_USER=your_user
DB_PASSWORD=your_password
```

## Model Performance

Trained on 2,000 synthetic student records with GridSearchCV:

| Model | R² | RMSE | MAE |
|---|---|---|---|
| Random Forest | ~0.93 | ~3.8 | ~2.9 |
| XGBoost | ~0.91 | ~4.1 | ~3.1 |
| Ensemble | ~0.94 | ~3.6 | ~2.7 |
